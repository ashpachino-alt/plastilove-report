# Как включить ежедневный отчёт через GitHub (бесплатно, без сервера)

Идея: GitHub будет сам запускать твой скрипт каждый день в 9:00 и слать отчёт в Telegram.
Комп при этом можно выключать. Настройка — один раз, ~15 минут, всё через сайт github.com.

---

## Шаг 1. Создать репозиторий (папку для кода на GitHub)

1. Зайди на **github.com**, войди в аккаунт.
2. Справа вверху **＋ → New repository**.
3. Имя: `plastilove-report`. Тип — **Private** (приватный, чтобы код никто не видел).
4. Кнопка **Create repository**.

## Шаг 2. Загрузить файлы проекта

1. На странице репозитория: **Add file → Upload files**.
2. Открой на компе папку `Downloads/ДАШБОРД` и перетащи в окно браузера **все файлы, КРОМЕ**:
   - ❌ `.env` (это секреты — их грузить нельзя!)
   - ❌ папки `raw/` и `reports/` (необязательно, генерируются сами)
   - ✅ обязательно нужны: `fetch.py`, `compute.py`, `report.py`, `xlsx_report.py`,
     `run_daily.py`, `requirements.txt`, и папка `.github`
3. Внизу нажми **Commit changes**.

> Если папка `.github` не перетаскивается — не страшно: создай файл вручную.
> **Add file → Create new file**, в имя впиши `.github/workflows/daily_report.yml`,
> и вставь туда содержимое одноимённого файла из проекта. Commit.

## Шаг 3. Вписать секреты (ключи — безопасно)

Ключи храним отдельно от кода, в зашифрованном хранилище GitHub.

1. В репозитории: **Settings → Secrets and variables → Actions**.
2. Кнопка **New repository secret** и добавь по одному (имя → значение):

| Имя секрета | Где взять значение |
|---|---|
| `OZON_CLIENT_ID` | из файла `.env` (строка OZON_CLIENT_ID=…) |
| `OZON_API_KEY` | из `.env` |
| `WB_API_TOKEN` | из `.env` |
| `TG_BOT_TOKEN` | из `.env` (уже вписан) |
| `TG_CHAT_ID` | из `.env` = 343319710 |

> Открой `.env` в папке `Downloads/ДАШБОРД` любым текстовым редактором и копируй значения (то, что после `=`).

## Шаг 4. Проверить — запустить вручную

1. В репозитории вкладка **Actions**.
2. Слева выбери **«Ежедневный отчёт PlastiLove»** → справа кнопка **Run workflow** → **Run workflow**.
3. Через несколько минут (WB тянется ~5–8 мин) отчёт придёт тебе в Telegram.
4. Если пришёл — всё, дальше он будет уходить **сам каждый день в 9:00**.

---

## Полезное

- **Поменять время.** В файле `.github/workflows/daily_report.yml` строка `cron: "0 6 * * *"` —
  это 06:00 UTC = 09:00 МСК. Хочешь другое время — считай от МСК минус 3 часа.
- **Если отчёт не пришёл.** Вкладка Actions → открой последний запуск → красный крест покажет ошибку
  (чаще всего — опечатка в секрете).
- **Задержка.** GitHub иногда стартует расписание на 5–15 минут позже — это нормально.
- **Бесплатность.** Приватный репозиторий: 2000 минут/месяц бесплатно. Один прогон ~8 минут ×
  30 дней ≈ 240 минут. С запасом влезает.
